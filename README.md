# Репозиторий технической документации PLM-Платформы

Данный репозиторий ведется по методологии **Docs-as-Code**. Вся проектная и техническая документация хранится в виде текстовых файлов в формате AsciiDoc (`.adoc`) совместно с кодовой базой и управляется через Git.

---

## Структура репозитория и назначение файлов

```text
OTUS 14/
├── docs/                           # Корневой каталог исходного кода документации
│   ├── assets/                     # Статические ресурсы, диаграммы и графики
│   │   └── architecture.puml       # Исходный код схемы контейнеров системы (PlantUML)
```

## Правила ведения документации (Docs-as-Code)

1. **Глобальные переменные:** Названия систем, года и версии запрещено хардкодить в тексте. Используйте атрибуты из `global/_attributes.adoc` (например, `{pricing_service_id}`).
2. **Обезличивание:** Все документы строго ролированы (например, *Ведущий системный аналитик*, *Технолог*). Имена сотрудников не используются.
3. **Модульность:** Разделы не должны превращаться в огромные "простыни". Используйте атомарные файлы и механизм разделения по папкам.
