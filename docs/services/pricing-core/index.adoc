== Назначение 
МкС предназначен для выполнения следующих функций:
* Приём запросов от интерфейса аналитиков на утверждение стоимости нового продукта.
* Валидация входящих коммерческих данных на соответствие схемам.
* Криптографическое полейное шифрование (Field-Level Encryption) поля цены перед сохранением.
* Публикация асинхронного события `PriceApproved` в центральный брокер Земли.

== Архитектура работы сервиса
Сервис работает в синхронном контуре Земли (SOA), принимая запросы через API Gateway. Перед отправкой события в шину данных для удаленных планет, сервис вызывает встроенный интерцептор `fle_interceptor` для защиты конфиденциальных полей.

== Детальное описание методов сервиса

== GetProductPricing
* *Название метода*: GetProductPricing
* *Путь метода*: `/api/v1/products/{product_id}/pricing`
* *Тип взаимодействия*: _синхронный_
* *Тип операции*: GET
* *Тип входящего сообщения*: http запрос, Content-Type: application/json
* *Тип исходящего сообщения*: http ответ, Content-Type: application/json
* *Влияние на группы продуктов*: не применимо
* *Описание очередей MQ*: топик `price-approved` (Earth Kafka Broker)
* *Бизнес-объект*: Тарифная сетка продукта (`Pricing_Object`)

=== Краткое описание метода
Метод возвращает стоимость новинки для мобильного приложения с зашифрованным значением цены (AES-GCM-256) для защиты от перехвата в космосе.

=== Алгоритм работы метода
. *Формирование и отправка запроса*
.. Мобильное приложение через API Gateway вызывает метод получения цены продукта по его `product_id`.
.. Выполняется проверка параметров запроса на соответствие UUID-формату.
... Если проверка неуспешна, возвращается HTTP code = 400, основной сценарий завершается.
. *Обработка результата операции*
.. Сервис вычитывает данные из `Commercial Pricing DB`.
.. Поле цены передается в FLE-интерцептор, шифруется ключом из KMS и упаковывается в пакет.
- Если при вызове хранимой процедуры или обращении к KMS произошла ошибка, то завершаем выполнение сценария с HTTP code = 500. Обработка основного сценария прекращается.

== Нефункциональные требования

=== Протоколирование работы
. Результаты работы сервиса должны логироваться.
.. Способ логирования: Запись структурированных логов в формате JSON в централизованную систему сбора логов бэк-офиса Земли. Шифрованные поля в логи не выводятся.

=== Политики обеспечения безопасности и целостности
Применение полейного криптографического шифрования (Field-Level Encryption) по алгоритму AES-GCM-256 для полей стоимости. Применение JSON Schema Validator для входящих пакетов.

=== Аутентификация и авторизация
. Необходимо использовать проверку прав доступа на базе RBAC/ABAC движка Open Policy Agent (OPA) на шлюзе API Gateway перед передачей запроса в микросервис.

=== Защищаемые объекты
. Размещение микросервиса и базы данных `pricing_db` исключительно во внутреннем защищенном контуре бэк-офиса Земли в AWS.
